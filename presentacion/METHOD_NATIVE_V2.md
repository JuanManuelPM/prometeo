# PROMETEO · PRESENTACIÓN WEB V2 · MÉTODO ONE-SHOT
**Plan inicial (antes del código).** Mantener la presentación de 7 slides, tipografía, diagrama y las dos flechas. Reemplazar solo el reproductor YouTube por `HTMLMediaElement` nativo. Recortar desde fuente autorizada, no desde YouTube. El navegador no debe cargar scripts, iframes ni CDNs externos. Github Actions puede producir MP4 sin instalar software en el teléfono. La demostración no requiere Canva.
**Batería de tests definida:** paridad visual en 1280×720 y 390×844, un solo par de botones, navegación manual y teclas, inicio con sonido, EOF, error de medio, desaparición del video al cambiar, cortes 65–77/142–153/220–230, temporizador automático, ausencia de llamadas a YouTube, audio/codecs y hash, served-byte GitHub Pages.
**Implementación V1.** Se produjo `index.html` con video nativo, 7 slides, metadatos de los cortes y soporte de autoplay restringido. Primer ensayo del servidor falló por bloqueo administrativo de navegación a localhost/file:// del Chromium de este entorno; no era un fallo del reproductor.
**Crítica.** Las pruebas del primer arnés no servían como evidencia; se reemplazaron por Playwright `page.set_content()` con MP4 H.264/AAC auténticos embebidos en datos locales. Resultado: 5 pruebas PASS; incluido time advancement, EOF, error de archivo, temporizadores y paridad pixel a pixel de portada. Eso no comprueba aún el film definitivo ni el audio en Android. Un embed en YouTube 4K/60 no se iguala bit a bit con fuente Blender 1080p/30.
**Plan final tras la crítica.** Usar ZIP oficial de Blender Foundation, extraer película en GitHub Actions, codificar 3 clips MP4 H264/AAC 1080p con faststart; usar `ffprobe` para verificar duración/codecs, generar SHA256, publicar la nueva ruta `/presentacion/v2/` en gh-pages sin tocar `/presentacion/`, y verificar las respuestas reales. Solo reemplazar la ruta aceptada después de que los clips sean públicos y reproducibles.
**Estado de publicación:** se diferencia código con tests locales de video real publicado; consultar corrida de GitHub Actions y ruta real antes de marcar SERVED.
