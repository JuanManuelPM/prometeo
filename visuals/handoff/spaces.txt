WHY THIS EXISTS
The v33 screenshot supplied by the user proved that technically correct code can still be visually bad. The pipeline is meant to remove the manual loop:
implement -> ask user for screenshot -> discover obvious failure -> repeat.

Now the intended loop is:
implement -> automatic deterministic screenshots -> visual critique -> correct obvious failures -> final delivery.
