CURRENT ENGINE MODEL
Trail should be reusable, not reauthored per image.

compileTrailAsset(image)
→ clean alpha / remove gray residue / crop / bound resolution
→ one repo-local sprite

TrailEngine(asset, trajectory)
→ same single sprite reused
→ bounded stamps {x,y,z,angle,yaw,scale,born}
→ projection / full-image redraw

See architecture.md for the durable technical model.
