CURRENT OBJECTIVE
Turn visual search into reusable preference-learning infrastructure for every Prometeo visual task.

CORE LOOP
search -> browse -> compare -> like/dislike -> tag/use-case -> save -> learn -> refine query -> search again

MVP REQUIRED
- free search;
- clean gallery;
- museum/large-item viewer with next/previous;
- LIKE / DISLIKE / SAVE;
- use-case tags;
- collections/favorites/rejected;
- persistent local data;
- original query + expanded query provenance per item;
- search history;
- editable query variants;
- A/B comparison: “which is better for X?”

LEARNING MODEL
Persist not just preference, but context/reason:
- better for Spaces;
- floor texture;
- wall pattern;
- hand idle;
- hand grab;
- avatar face/body/limb;
- Trail silhouette;
- brutalist scale;
- too clean / too dark / too generic;
- production-useful vs reference-only.

Use history transparently:
- boost terms/combinations associated with saved/A-B winning items;
- reduce terms associated with repeated rejection;
- show why a query variant was generated;
- do not pretend this is magical ML if it is rule/history based.
