Qué está usando realmente esta página

Usa SpeechRecognition (o webkitSpeechRecognition) del navegador con continuous = true e interimResults = true. No hay Whisper, no hay clave de API y esta página no envía audio a un servidor propio.

Importante: “gratis” no significa necesariamente “100% local”. Algunos navegadores, especialmente Chrome, pueden usar un servicio de reconocimiento remoto del propio navegador. La implementación depende del navegador.

Demo estática. Todo el JavaScript está en este mismo HTML. Si el navegador no expone SpeechRecognition, la página lo detecta y no finge que funciona.
