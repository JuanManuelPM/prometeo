# Reference implementation — Modelos y Teorías II

Reference URL:

`https://juanmanuelpm.github.io/prometeo/pages/modelos-teorias-ii.html`

This page is evidence for Study System V2, not a universal template to clone verbatim.

## What survived iteration

- Two-color themes, including strong dark variants.
- Dense closed overview; deeper explanation only on demand.
- Persistent recall checks and progress.
- A top transversal history/philosophy map suited to this subject.
- Narrative summaries above atomized author checks to prevent fragmentation.
- Practice separated from the study map.
- Desktop and phone require different compositions.
- One coherent typographic system matters more than decorative variety.

## What must not become baseline

- Linear sprint/race as the main information architecture.
- Isolated checkboxes without a connected explanation layer.
- Generic AI instructions occupying study space.
- Informational chips/cards styled as controls.
- One-off CSS accumulation as long-term engine architecture.
- Loader/base64/chunk mechanisms as canonical storage.

## Modelos-specific transversal map

`philosophical roots → previous lines → antecedents → first revolution → symbolic paradigm → second revolution`

Within it, the useful recall atoms were mostly `author → contribution` associations. Other subjects should generate different transversal maps.

## Evaluation lesson

The known format emphasized development questions and case interpretation. Multiple choice was useful as rapid discrimination/coverage QA rather than as exam simulation. Evaluation evidence such as review questions, sample cases and the class immediately preceding an exam deserves a distinct source role.

## Whiteboard prototype seed

Modelos is a useful test corpus for mnemonic thumbnails because names such as Sócrates, James, Tolman, Bruner or Bordin have compact conceptual anchors that can be paired with personal drawings without replacing or altering the authoritative explanation.
