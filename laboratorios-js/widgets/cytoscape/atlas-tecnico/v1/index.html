Atlas de relaciones

Grafo bibliográfico con búsqueda, foco, grupos, selección doble, comparación explicada y fuentes.

Construcción y pruebas
Orden: Recuperar grafo original → validar modelo → búsqueda → foco → ficha editorial → grupos → comparador → exportación → pruebas.

Pruebas: Búsqueda tolera acentos, selección preserva aristas, A/B muestra vecinos comunes correctos, navegación por teclado y táctil a 360px.

Extensión: Importar referencias académicas con citas verificables.

Construcción y pruebas
Orden: Modelo y comandos → canvas Cytoscape → controles y parámetros → algoritmos → undo/redo → serialización → pruebas.

Extensión: Análisis de conectividad y detección de comunidades.
