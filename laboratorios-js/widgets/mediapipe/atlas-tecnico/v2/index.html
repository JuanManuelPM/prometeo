mp-01 · course

Seguimiento de manos

De captura a 21 landmarks reutilizables

Cómo se construye
  1. VideoCapture
  2. validación de frame
  3. BGR→RGB
  4. Hands.process
  5. comprobar multi_hand_landmarks
  6. enumerar 21 landmarks
  7. convertir x,y por anchura/altura
  8. FPS
  9. encapsular detector.

Datos: HandFrame={t,hands:[{points[21],handedness}]}; px=(x*width,y*height).

Errores y correcciones

El video enseña módulo Python reutilizable. Corrección: descartar datos ausentes, reconciliar identidad y usar MediaPipe Tasks JS moderno para web.

Variaciones y pruebas

Ideas: Escultura; cursor de acceso; edición textil.

Comprobación: 0/1/2 manos y pérdida en drag sin error.

mp-02 · course

Estimación de postura

Del cuerpo a movimientos expresivos

Cómo se construye
  1. Capturar video
  2. Pose.process sobre RGB
  3. obtener 33 landmarks
  4. escala a píxeles
  5. conservar visibility y z
  6. dibujar solo para debug
  7. módulo findPose/findPosition.

Datos: PoseFrame={joints[33]:{x,y,z,visibility}}; joints indexados.

Errores y correcciones

El video muestra tracking en CPU. Corrección: las articulaciones ocluidas se estiman; no generar eventos si visibilidad cae.

Variaciones y pruebas

Ideas: Teatro de sombras; títeres; bosque reactivo.

Comprobación: Sin pose retorna vacío; ocultar articulación no dispara gesto.

mp-03 · course

Detección facial

Cajas para rostro sin identidad

Cómo se construye
  1. FaceDetection.process
  2. recorrer detections
  3. obtener score y relative_bounding_box
  4. normalizar a píxeles
  5. dibujar rectángulo/esquinas
  6. módulo findFaces.

Datos: faces=[{bbox:[x,y,w,h],score}]

Errores y correcciones

Un umbral 0.75 del ejemplo quitó falsos positivos observados; corregir con validación de falsos negativos y umbrales configurables.

Variaciones y pruebas

Ideas: Máscaras teatrales; encuadre grupal.

Comprobación: Sin detección [] y bounding boxes dentro de pantalla.

mp-04 · course

Malla facial

468 puntos por rostro

Cómo se construye
  1. Configurar FaceMesh y max_num_faces
  2. RGB→process
  3. recorrer multi_face_landmarks
  4. separar por cara
  5. extraer índice y coordenadas
  6. overlay opcional

Datos: faces[faceIndex][468] con x,y,z.

Errores y correcciones

03 · Reproducción desde cero

De una cámara a una herramienta

Adaptadores de entrada

La cámara, mouse y táctil deben terminar en el mismo mensaje para el motor de interacción. La escena no debería consultar directamente el flujo de video.

Action = {source,phase,x,y,t,confidence}
input → gestureState → Action
pointer → pointerAdapter → Action
Action → sceneReducer → render

Pinza estabilizada

Usar distancias relativas a la mano y umbrales de entrada/salida distintos; confirmar durante varios cuadros y cancelar ante pérdida de detección.

pinch = dist(hand[4],hand[8]) / palmWidth
if !grabbing && pinch < enter: begin()
if grabbing && pinch > exit: release()
if handLost: cancelSafely()

Casos de aceptación

Pinza sostenida inicia una sola vez; perder la mano suelta sin desplazar objeto; permiso denegado conserva funcionamiento manual; exportación e importación restauran resultado; no hay transferencias de imágenes. Tests unitarios, de integración y navegador en hardware antes de decir que un producto está verificado.

[VIDEO]: lo relatado en la fuente. [CORRECCIÓN]: mitigación técnica propuesta. [INFERENCIA]: deducción no demostrada. [EXTENSIÓN]: aplicación nueva. [INVESTIGACIÓN]: API confirmada por documentación externa.
