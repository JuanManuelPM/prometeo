Restricciones y próximas acciones

• El único tutorial aportado fue una transcripción sin URL, autor ni duración; no se observaron fotogramas.

• Las referencias externas fueron consultadas como documentación/repositorios, no ejecutadas ni auditadas en dispositivo.

• PDF escaneados requieren OCR adicional; EPUB con DRM no está soportado.

• El iframe de Laboratorios JS carece de same-origin: localStorage no es base de persistencia. Usar importación/exportación y evaluar persistencia en ventana aislada.
