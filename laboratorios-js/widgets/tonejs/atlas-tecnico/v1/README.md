# Atlas técnico Tone.js · v1

**Naturaleza:** publicación de conocimiento, no los tres productos musicales. Tema: composición indie, secuenciación, captura, instrumentos, audio adaptativo y calidad.

- `index.html`: atlas autónomo para iframe sandbox con datos embebidos, búsqueda y filtros sin llamadas externas.
- `atlas.json`: conocimientos estructurados reutilizables por otras IA.
- `plan.json`: fase 2 ejecutable con tres productos, rutas, arquitectura y pruebas.
- `PLAN_EJECUTABLE.md`: lectura humana del plan.

**Fuentes primarias:** dos transcripciones aportadas por el usuario. Las URLs/fechas/autores completos de sus videos no fueron aportados. No se reproduce el texto integral. No se publican archivos de audio ni material privado.

**Antecedente:** Sendero Music Studio desarrollado localmente y no publicado como app Tone.js. Su núcleo es Web Audio nativo, con Tone.js opcional, y su sonoridad no recibió evaluación humana verificable.

**Reproducción:** abrir `index.html` en navegador directamente, o dentro del iframe de `laboratorios-js/`. No necesita red, npm, claves ni permisos. El propio conocimiento está embebido y el JSON externo es para acceso de máquinas.

**Fase 2:** sólo cuando un mensaje `.` autorice construir las tres experiencias, y publicar exclusivamente las que pasan pruebas. La Fase 1 no las implementa.
