# prometeo-verify-release

Read Constitution and `coordination/design-dna/PRESERVATION_CONTRACT_V1.json`, exact Current/Lineage and Page Change Feed owner.
- Separate IMPLEMENTED / CANDIDATE / TESTED / INDEPENDENT_VERIFIED / PROMOTED / CURRENT / SERVED. A git commit alone is not a served webpage.
- Re-fetch branch/head, verify exact write scope, test both delta and preserved behavior, negative tests, browser/mobile, full asset closure and rollback. Declare unavailable tests UNVERIFIED.
- Confirm input and output **durable owner receipts**; a committed contract is not proof private messages were saved. Unverified private write => PERSISTENCE_BLOCKED.
- For UI "live" requires fresh actual worker evidence; a claim timestamp, timer, or historical RETURN is not a running process. DONE != PASS.
- No producer self-promotion, unapproved release or credentials/public transcripts. Record source, evidence time, verification result, prior version, authorized promotion and exact-next.
