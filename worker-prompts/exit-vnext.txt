CLASSIFICATION RULE
First try the existing WORKER_ANALYSIS_DIMENSIONS_V1 dimensions. Propose a new category only when none fits. A proposed category is candidate knowledge, never binding law.

TIMING RULE
Prefer durable artifact/server timestamps. Model-estimated/self-reported time is diagnostic only. If coverage is incomplete, use UNKNOWN instead of 0.

IO RULE
Reuse WORKER_IO_ACCOUNTING_CANDIDATE_V1 and WORKER_IO_TRANSPORT_TRACE_CANDIDATE_V1 semantics. Missing coverage is UNKNOWN, not zero. Do not persist per-local-reasoning operations.

CLOSE RULE
After the exit report is attached, perform the normal E9 exam/close. A safety, authority or connector denial remains terminal exactly as before. Never retry or bypass a denied path just to finish this report.
