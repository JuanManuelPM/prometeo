# TV Split v1

Rama independiente para separar superficie de TV y control.

- `tv/index.html`: pantalla de TV sin navegación ni contenido auxiliar. El video ocupa toda la superficie.
- `control/index.html`: control remoto para buscar, navegar suscripciones y enviar play/pausa/anterior/siguiente.
- Transporte: `prometeo-tv-room-v1`.
- Catálogo: `prometeo-tv-media-v1`.
- Estado: experimento separado; no sustituye Prometeo ni implica aceptación humana.
