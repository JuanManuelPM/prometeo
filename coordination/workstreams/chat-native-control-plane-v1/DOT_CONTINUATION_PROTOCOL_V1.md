# Dot Continuation Protocol v1

Status: BINDING INTERACTION CONTRACT
Owner: `chat-object-prometeo-chat-control-main`

## Purpose
A bound parent must treat a bare `.` as permission/instruction to continue the highest-value safe frontier from durable state. The human should not need to restate the plan.

## On every `.`
1. Reincarnate/resync this Chat Object from stable durable state.
2. Refresh current epoch/head and relevant worker claims/runs/returns.
3. Detect new RETURNs, failures, stale runs, blocked dependencies and unconsumed proposals.
4. Reconstruct current campaign/frontier from FOCUS + Continuity/Work state.
5. Execute useful parent work immediately instead of merely reporting status.
6. If a new parallel wave is useful, prepare executable opportunities/jobs before asking the human to open chats.
7. If generic self-assigning workers are operational, ask only for repeated use of the single generic worker bootstrap, with a count if useful.
8. If generic workers are not yet operational, minimize temporary launch friction and keep building toward them.
9. Persist any changed plan/frontier/negative knowledge before replying.
10. Human-visible reply should be short unless a real decision/boundary requires explanation.

## Prohibited behavior on `.`
- asking the human what they want to do next when durable state already says;
- asking which workers were launched;
- asking for worker answers to be copied back;
- restating the entire plan instead of acting;
- switching to Live/UI polish while higher-priority control-plane work remains;
- treating stale transcript salience as current priority;
- waiting idly for one worker when independent parent work can continue;
- spawning redundant work solely to consume available chats.

## Current meaning
Until superseded, a dot on `chat-object-prometeo-chat-control-main` means:

`finish B-BIGPIC-01 -> converge returns -> compile Architecture/Active Method vNext -> implement autonomous swarm kernel -> bind Facultad/Alumnos roots -> test generic identical worker swarm -> migrate Prometeo onto that loop`

The exact current substep must be derived from durable state at execution time.
