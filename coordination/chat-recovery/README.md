# Prometeo · Chat Recovery

Status: **NON_AUTHORITATIVE_RECOVERY_PROJECTION**

This directory is a locator and distilled-knowledge catalog for historical/discovered conversations. It does **not** replace Chat Sessions, Chat Object, Work Context, Current Tree V2, Organism, Design DNA, or any product authority.

Use `INDEX.json` to find chats by topic, `entries/` to reopen a source through descriptive anchors, `LINEAGE.json` to follow conceptual/implementation ancestry, and `reports/` to avoid repeating a previous recovery run.

Historical chats may be indexed here without being adopted as modern Chat Sessions.
