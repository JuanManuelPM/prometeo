# Study Library V11 — release notes

- Restores the early bookshelf + calendar product direction on top of the live V4→V10 functional stack.
- Uses Blackboard-discovered courses as the normal library catalog when available instead of showing the old hardcoded filler catalog as authority.
- Adds integrated month/week/agenda views from Blackboard + assessment registry sources.
- Replaces the technical Blackboard strip with source behavior inside courses/materials/calendar.
- Adds richer course-open hierarchy with cover identity, next assessment, last class and source freshness.
- Adds a real Materials tab fed by Blackboard content.
- Keeps existing live class, Walky, voices, recording, transcription, shared notes and V10 class boards intact.
- Adds a generic Study System V2 renderer and a non-promoted Modelos P1 schema migration shadow.
- Stages Blackboard Bridge 0.4.0 with better course canonicalization, known-course crawling and file-mirror diagnostics.

Not claimed as closed: browser visual QA, Bridge 0.4 runtime validation/file mirror, complete detailed Modelos P1 schema extraction, two-device class QA, stylus/touch hardware QA, CRDT-per-stroke whiteboard collaboration, persistent signed Firefox distribution.
