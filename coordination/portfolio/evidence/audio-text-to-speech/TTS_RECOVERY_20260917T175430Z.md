## Verdict

The implementation already exists. Do **not** rebuild the TTS stack from scratch.

The recovered system has three distinct layers:

1. **Public comparison surface** — `audio-lab-public` publishes a static HTML snapshot to `public-pages/audio-lab-v5.html` and redirects to it.
2. **Paragraph/voice comparison backend** — the Audio Lab UI uses `modelos-room-audio-v2`, which is an active Supabase Edge Function backed by `modelos-qwen-tts-v2`, server cache, and Qwen3-TTS.
3. **Generic long-text generation backend** — `audio-lab-page-audio-v1` accepts arbitrary `text`, `voicePrompt`, and `messageId`, with a hard max of 1800 characters and shared cache in `casa_audio_cache`.
