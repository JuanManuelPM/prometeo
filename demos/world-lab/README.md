# WORLD LAB

WORLD LAB is the executable visual bible / test room for Prometeo WORLD.

It is intentionally separate from `demos/coliseo-3d/`.

## Purpose

- prototype visual primitives without touching canonical WORLD;
- compare avatar states, block materials, work pads, roads and transport;
- test architecture pieces and information panels in isolation;
- run camera / projection regression checks;
- exercise synthetic graphs before dynamic layout reaches the live world;
- make CANON / PROTOTYPE / NEEDS FIX / IDEA visible in one surface;
- keep local notes in browser storage and export a JSON snapshot.

## Hard rule

A feature may be demonstrated in WORLD LAB without being promoted to WORLD.
Promotion requires explicit acceptance of the primitive and its regression tests.
