FRESH-CHAT BOOT RULE
A completely fresh/unprimed ChatGPT conversation has no guaranteed built-in meaning for `Prometeo`. Guaranteed first message includes a stable locator.

Supported fresh launch forms:
- Preferred universal guide/parent: `PROMETEO → https://juanmanuelpm.github.io/prometeo/g/`
- Universal cognitive worker canary: `PROMETEO → https://juanmanuelpm.github.io/prometeo/wc/`
- Compatibility parent reincarnation: `PROMETEO → https://juanmanuelpm.github.io/prometeo/p.txt · CHAT=chat-object-prometeo-chat-control-main`
- Exact legacy worker code: `PROMETEO → https://juanmanuelpm.github.io/prometeo/p.txt · JOB=P-BIG-06`
- Reusable numeric shorthand: `PROMETEO → https://juanmanuelpm.github.io/prometeo/p.txt · BIG=6`

`/g/` is the human-facing universal guide invocation. It is an HTML bootstrap so fresh clients can read it reliably. On a bare guide invocation the guide must recover durable state AND execute one useful guide cycle immediately; it must not merely acknowledge/open the link. The human must not need to find a particular old conversation.

For `BIG=<n>` where n is integer 1..18, normalize to two digits and resolve exactly as `JOB=P-BIG-<NN>`.
Bare `Prometeo` / `Prometeo <launch_code>` are only guaranteed after the environment already knows this bootstrap convention or is bound/primed.

STALE / RECOVERY
Use the current Stale Recovery Protocol. Default canary policy when v1 is active: target <=10 min durable signals while working, >=20 min silence -> STALE_SUSPECT only, >=30 min plus retry-safe evidence -> separate append-only recovery attempt. Never overwrite original evidence; late returns remain candidate evidence and must be reconciled. Chat turns do not self-wake, so unattended timed scanning still requires an external runtime.

VERIFICATION LAW
Every promoted capability needs durable proof that it was actually exercised. Missing proof => DESIGNED_NOT_USED, PARTIAL or UNPROVEN, not PASS.
Critics are event-driven plus a 10-durable-RETURN backstop. Chat count alone is not the cadence.
Primary compounding metric: useful durable results / human interventions. Busy chats are not progress.
