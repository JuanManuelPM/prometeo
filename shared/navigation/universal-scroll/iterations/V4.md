# V4 — Universal Surface

Status: CANDIDATE / NOT CURRENT
Preview: `lab/universal-shell/v4/`

## Purpose

Integrate the permanent interaction/design laws learned through V1–V3 into one specimen without adding explanatory chrome.

## What V4 demonstrates

- blank app surface: no app name, breadcrumb, counter, status dot, scroll hint, footer, or explanatory labels
- one dominant destination surface
- active destination contains useful real child names rather than decorative descriptions
- Edge Stack shows only up to three upcoming destinations; distant destinations consume zero visible space
- desktop and iPad landscape use native horizontal scroll
- iPad portrait and narrow/mobile use native vertical scroll
- shared `material/v1` owns physical depth and controls
- shared `interaction/touch-first/v1` owns pointer/touch/pen press behavior and mouse contact proxy
- hover is optional only
- Enter arrow is the single visible open action
- Back appears only after entering a nested level
- recursive navigation remains data-driven
