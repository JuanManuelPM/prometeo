# Prometeo Physical Material v2 — candidate

## Corrected law

**Depth communicates manipulability.**

- Page/content/shell surfaces: flat by default.
- Manipulable controls: dark external drop/ledge + subtle internal light.
- Press: physically collapses toward the base plane.
- Inset: only for an actual receiving/adjusting field, not decoration.
- Hover: optional fine-pointer enhancement only.

This deliberately differs from Material v1, whose owner document explicitly raised windows/surfaces/shells. V1 remains untouched for regression safety; V2 is opt-in until representative consumers are visually accepted.
