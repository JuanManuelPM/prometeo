# PROMETEO GENERIC REINCARNATION PROTOCOL V1

Status: CURRENT fallback protocol.

The normal Control Room V11 path is direct page feedback → workers. Reincarnation is a manual fallback for work that benefits from an interactive chat.

A new chat receives a page/workspace identity and must:

1. Read `https://juanmanuelpm.github.io/prometeo/p.txt`.
2. Read `catalog/CATALOG_MANIFEST.json` and resolve the exact page/source owner.
3. Resolve Current Tree / Organism / Semantic Registry when relevant.
4. Inspect the actual repo target before asserting implementation state.
5. Recover durable page/workspace continuity from available Work Context / Page Memory / Visual front package.
6. Distinguish accepted baseline, current candidate, open feedback and rejected/negative knowledge.
7. Return a concise readback and do not edit until explicit ACTUALIZÁ/equivalent.
8. On update: implement, test/verify, persist source-owner changes and durable RETURN/continuity, then assume the chat will be discarded.

Never use chat history as authority and never ask the human to manually re-send context already available in Prometeo.
