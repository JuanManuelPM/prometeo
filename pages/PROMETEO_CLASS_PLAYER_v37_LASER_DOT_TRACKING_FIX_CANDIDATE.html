Sistema permanente

Una página final se puede tirar. El kit modular se conserva.

El objetivo no es solo crear una clase: es darle a cualquier IA un lenguaje de componentes, recetas, temas, tips inteligentes y reglas para construir páginas interactivas.

Regla madre
La IA no inventa interfaz: elige receta, componentes y completa datos.

La clase es una receta. Una landing, una guía o un dashboard usan el mismo kit.

Flujo para otra IA

Primero decide la receta. Después rellena bloques.

El ZIP debería permitir que otra IA construya una página sin diseñar desde cero: detecta intención, elige layout, selecciona componentes y genera el HTML final.

Prompt humano ideal

“Usá este kit. Armame una página para explicar este proyecto.”

La IA lee recetas, usa schemas y devuelve una página terminada.

1. Un móvil parte a \(2\,m/s\), acelera a \(3\,m/s^2\) durante \(4s\). Calcular \(v_f\). Física · MRUA · respuesta con unidad
Ver ayuda opcional
Fórmula útil
\[ v_f = v_i + a \cdot t \]

No aparece de entrada: el alumno puede intentar primero.

Mostrar tips inteligentes
Tip 1: si la consigna dice “durante 4s”, probablemente el tiempo entra directo en la fórmula.
Tip 2: si pide velocidad final, no hace falta calcular posición.
Tip 3: antes de hacer cuentas, escribí las unidades para no mezclar \(m/s\) con \(m/s^2\).
Ver resolución modelo
1Identificar datos
\(v_i=2\,m/s\), \(a=3\,m/s^2\), \(t=4s\).
2Reemplazar
\(v_f=2+3\cdot4\)
3Cerrar
\(v_f=14\,m/s\)

Respuesta esperada

Datos: \(v_i=2\,m/s\), \(a=3\,m/s^2\), \(t=4s\)
\(v_f=v_i+a\cdot t\)
\(v_f=2+3\cdot4=14\,m/s\)
