# Prometeo · Universal Hub

Este repositorio es el registro estable de accesos humanos a los proyectos vivos de Prometeo.

- `index.html`: launcher humano.
- `projects.json`: registro estructurado de proyectos, URLs públicas y estado de verificación.
- Los proyectos grandes pueden vivir en repositorios independientes; este repo apunta a sus URLs vivas.
- No promover una URL histórica a `live` sin readback/verificación actual.
- Al crear o mover un proyecto, actualizar `projects.json` y la proyección de `index.html`.

La intención es que el humano use un único acceso público y no tenga que operar GitHub para mantener enlaces o reemplazar archivos.
